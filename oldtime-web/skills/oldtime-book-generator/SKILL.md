# oldtime-book-generator

## 目标

把老人输入的照片故事整理成一本「旧时光 OldTime」数字纪念册的数据结构，用于前端阅读页、分享页和后续视频导出。

## 输入

```json
{
  "ownerName": "张爷爷",
  "serial": 2,
  "pages": [
    {
      "pageIndex": 1,
      "imageUrl": "https://example.com/photo-1.jpg",
      "rawStory": "这是我和老战友在公园重逢。"
    }
  ]
}
```

## 输出

```json
{
  "title": "老战友的重逢",
  "subtitle": "把那些值得想起的日子，珍藏成一本书",
  "theme": "years_gold",
  "archiveNo": "OT-2026-002",
  "certificateText": "这本纪念册记录了张爷爷的一段珍贵旧时光。愿每一次翻阅，都能想起那天的温暖。",
  "pages": [
    {
      "pageIndex": 1,
      "imageUrl": "https://example.com/photo-1.jpg",
      "rawStory": "这是我和老战友在公园重逢。",
      "chapterTitle": "第一章 · 老友重逢",
      "polishedStory": "这是我和老战友在公园重逢。 这一天的笑声和心情，都被好好珍藏了下来。"
    }
  ]
}
```

## 文风规范

- 温暖、克制、有馆藏感。
- 不编造用户没有说过的事实。
- 不使用夸张营销词。
- 每页故事尽量短，适合手机端大字号阅读。
- 标题像纪念册，不像广告标题。
- 保留老人原话里的生活感。

## 主题规范

MVP 只启用 `years_gold`，对应「岁月鎏金」主题。

颜色倾向：

- 古董白 `#F8F5EE`
- 赭石色 `#8B4513`
- 真金色 `#D4AF37`
- 墨黑色 `#2D2318`

## 错误处理

如果用户没有输入故事，应生成一段兜底文案，表达“这一刻值得珍藏”，但不要假装知道照片内容。

如果故事太长，应保留前半段事实并温和收束。

如果无法调用大模型，应使用本地规则生成标题、章节和润色文字。
