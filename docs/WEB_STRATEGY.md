# 旧时光 Web 产品目标

> 本文回答一个问题：**这个产品最终要做成什么样。**  
> 这是目标和验收标准，不是当前实现；当前代码状态以 [ENGINEERING.md](ENGINEERING.md) 为准。  
> 原始产品方案见 [PRODUCT.md](PRODUCT.md)。

---

## 1. 终极目标

让 60+ 老人**不需要学习**，就能在 5 分钟内把照片和亲口讲述的故事，变成一本**可翻阅、可聆听、可分享、可打印**的数字纪念册。

子女可以远程参与，但老人始终是主角。

## 2. 一句话定位

旧时光不是相册，不是修图工具，也不是 H5 编辑器。

它是**老人的数字藏品**：像博物馆里的一本书，值得被郑重地制作、翻阅和送出去。

## 3. 目标用户与核心场景

| 角色 | 他们想做什么 | 产品要提供什么 |
|---|---|---|
| 老人 | 把最近的照片整理成一本册子 | 打开就能选图，按住就能说话，一键成书 |
| 老人 | 把册子发给老战友、家人 | 一个链接或二维码，对方直接能翻 |
| 子女 | 帮父母补写故事、挑照片 | 收到协作链接，远程编辑，完成后通知父母 |
| 家庭 | 多年后还能翻看、打印 | 收藏馆、长期保存、PDF/打印 |

核心场景只有三个：

1. **做一本**：选照片 -> 讲故事 -> 入藏。
2. **送出去**：分享链接/二维码，家人打开就能看。
3. **一起做**：子女远程协作，不让老人卡在“不会写”。

## 4. 产品原则

来自原始方案，后续所有功能都以此为准：

1. **不教育用户**：没有教程、没有新手引导、没有“点击这里”的箭头。
2. **不给选择**：主题、字体、版式由系统保证，老人只做“选照片、说话”两件事。
3. **不打断情绪**：从打开到分享，中间不出现注册弹窗、权限弹窗、复杂表单。
4. **不忽视反馈**：录音、保存、分享、协作完成，都要有明确反馈。
5. **不牺牲精美**：适老化不等于简陋，视觉必须像馆藏品。
6. **不追求科技感**：羊皮纸、赭石、烫金，优于炫技的 3D 和粒子。
7. **数据不丢**：断网、刷新、换设备，草稿和作品都不能丢。

## 5. 最终形态（什么叫做完了）

当下面 8 件事都能做到，这个产品就算真正完成：

1. **语音讲述**  
   老人按住屏幕说话，松手结束；可以播放原声；文字是辅助，不是门槛。

2. **离线可用**  
   选完照片断网，草稿还在；恢复网络后自动继续上传和生成。

3. **一键成书**  
   系统用规则生成标题、章节和润色文字；不需要老人写字，也不需要 AI。

4. **翻阅体验**  
   封面、内页、收藏证书完整；有翻书动效；大字号、高对比；可以听。

5. **分享**  
   链接、二维码、微信分享都可用；接收方换设备也能打开。

6. **亲子协作**  
   子女打开链接就能帮写故事；父母能看到“正在编辑/已完成”。

7. **导出**  
   可以导出 PDF 或打印，变成真正能拿在手里的纪念册。

8. **PWA**  
   可以安装到手机桌面；离线能打开最近一本书；像 App 一样使用。

附加但重要的：

- **无障碍**：大触控区域、高对比、语音引导，不依赖识字。
- **长期保存**：书籍、照片、音频都在服务端有归属和备份。

## 6. Web 端边界

- 先做 **Web + PWA**，验证产品；暂不做原生 App。
- **不接 AI Agent / LLM**；文案用规则模板，语音只录音不转写。
- 不做社交信息流、云盘、复杂编辑器。
- 商业化（会员、支付、水印）后置，先把“做一本、送出去”跑通。
- 不追求大而全；每个阶段只保证一条完整体验。

## 7. 成功标准

**北极星指标**（来自原始方案）：每月每用户制作纪念册数。

产品体验标准：

- 老人能在 5 分钟内独立完成一本。
- 分享链接在另一台设备上能直接打开。
- 断网、刷新、误关页面，不丢草稿。
- 子女能在 3 分钟内完成一次协作补写。
- PWA 可安装，离线能打开最近一本书。

> 这些是待验证的目标，不是已经达成的数据。

## 8. 产品里程碑

### M1：能做完一本

选照片 -> 语音讲述 -> 规则成书 -> 阅读 -> 分享。

### M2：能送出去

亲子协作、完成通知、PDF/打印。

### M3：能留下来

PWA 安装、离线阅读、书籍归属、收藏馆、回访。

### M4：能持续

三套主题、BGM、会员/支付、数据统计与运营。

## 9. 明确不做

- 不做 AI Agent、AI 文案、语音转写。
- 不做 React Native / 原生 App（至少 Web 验证前不做）。
- 不做 Next.js 重构、微服务、Postgres/Redis 全家桶。
- 不做社交广场、公开内容流。
- 不先做 3D WebGL、视频生成。
